Spending: run the wallet locally

    

      To send LATT you run latwalletgui on your own machine. It serves the same
      kind of interface at 127.0.0.1:8090, talks to your own node, and keeps the
      keys where a website can never reach them.
    

      
task build:latwalletgui
./bin/latwalletgui -conf ~/.latticed/latticed.conf

    
It prints a URL with a one-time token. Open that and you have the full wallet.

  






  Lattice reads this page from a read-only node API. No account, no cookie, no tracking.
