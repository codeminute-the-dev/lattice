* The the Lattice contributors Lattice-related Go Packages:
  * [rpcclient](https://github.com/codeminute-the-dev/lattice/node/tree/master/rpcclient) - Implements a
    robust and easy to use Websocket-enabled Lattice JSON-RPC client
  * [btcjson](https://github.com/codeminute-the-dev/lattice/node/tree/master/btcjson) - Provides an extensive API
    for the underlying JSON-RPC command and return values
  * [wire](https://github.com/codeminute-the-dev/lattice/node/tree/master/wire) - Implements the
    Lattice wire protocol
  * [peer](https://github.com/codeminute-the-dev/lattice/node/tree/master/peer) -
    Provides a common base for creating and managing Lattice network peers.
  * [blockchain](https://github.com/codeminute-the-dev/lattice/node/tree/master/blockchain) -
    Implements Lattice block handling and chain selection rules
  * [blockchain/fullblocktests](https://github.com/codeminute-the-dev/lattice/node/tree/master/blockchain/fullblocktests) -
    Provides a set of block tests for testing the consensus validation rules
  * [txscript](https://github.com/codeminute-the-dev/lattice/node/tree/master/txscript) -
    Implements the Lattice transaction scripting language
  * [btcec](https://github.com/codeminute-the-dev/lattice/node/tree/master/btcec) - Implements
    support for the elliptic curve cryptographic functions needed for the
    Lattice scripts
  * [database](https://github.com/codeminute-the-dev/lattice/node/tree/master/database) -
    Provides a database interface for the Lattice block chain
  * [mempool](https://github.com/codeminute-the-dev/lattice/node/tree/master/mempool) -
    Package mempool provides a policy-enforced pool of unmined Lattice
    transactions.
  * [btcutil](https://github.com/codeminute-the-dev/lattice/node/tree/master/btcutil) - Provides Lattice-specific
    convenience functions and types
  * [chainhash](https://github.com/codeminute-the-dev/lattice/node/tree/master/chaincfg/chainhash) -
    Provides a generic hash type and associated functions that allows the
    specific hash algorithm to be abstracted.
  * [connmgr](https://github.com/codeminute-the-dev/lattice/node/tree/master/connmgr) -
    Package connmgr implements a generic Lattice network connection manager.
